# 🧠 DSA Tutor

An AI-powered Chrome extension that helps users solve DSA problems through guided hints instead of directly providing solutions.

## Features

### Phase 1
- Chrome Extension using Manifest V3
- LeetCode problem detection
- Codeforces problem detection
- Problem title extraction
- Problem statement extraction
- Floating DSA Tutor interface

### Planned Features

- AI-powered DSA chatbot
- Problem-specific question answering
- Progressive hint system
- Code debugging
- Complexity analysis
- LeetCode and Codeforces support
- Problem-solving history
- User progress tracking

## Tech Stack

- JavaScript
- Chrome Extension Manifest V3
- HTML
- CSS
- Node.js
- Express
- AI API
- MongoDB
